# Mis rutas y trails

App web instalable con rutas de senderismo, trail, carreras y MTB de toda España.

- `index.html`: la app (los datos del usuario se guardan solo en su móvil).
- `eventos.json`: lista de eventos, actualizada cada mañana a partir de webs públicas de inscripción y cronometraje. Comprueba siempre los datos en la web oficial de cada evento.

Para instalarla en el iPhone: abre la web en Safari › Compartir › «Añadir a pantalla de inicio».
